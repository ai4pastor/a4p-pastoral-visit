# A4P Pastoral Visit

성도 명부와 심방 기록을 하나의 흐름으로 관리하는 옵시디언 플러그인입니다.

> **"타이핑은 목양 내용에만, 구조는 플러그인이."**
> 목회자가 손으로 쓰는 것은 대화내용·기도제목·후속조치뿐 — 파일명, 프론트매터, 링크, 임베드, 상태 갱신은 플러그인이 만듭니다.

## 주요 기능 (v0.1)

- **새 성도 등록** — 모달 입력만으로 표준 프론트매터를 갖춘 교인노트 생성. 동명이인 안전 처리 (기존 노트 덮어쓰기 없음)
- **심방일지 작성** — 메타 정보(성도·날짜·장소·유형)만 고르면 파일명 규칙(`{YYMMDD}_심방일지_{이름}`)과 7개 섹션 골격, 기본정보 자동 채움까지 완료. 커서는 대화내용에서 시작
- **성도 노트 반영** — 일지를 다 쓰면 클릭 한 번으로 성도 노트에 링크 + 요약(자동 제안) + 섹션 임베드 3종 추가, 심방상태 갱신. **미리보기 승인 후 실행, 기존 줄은 절대 수정하지 않음(append-only), 중복 반영 차단**
- **심방 대시보드** (사이드 패널) — 미완 후속조치 · 심방 필요 · 장기 미심방 · 생일 · 새등록 성도 · 미반영 일지
- **후속조치 추적** — 전체 일지의 체크박스를 모아 보여주고 패널에서 바로 토글
- **개인정보 보호** — 화면 마스킹 토글(파일은 불변), 동기화·git 노출 점검(경고만). 외부 전송 제로: 모든 처리는 로컬 볼트 안에서만

## 설치 (BRAT)

1. 커뮤니티 플러그인에서 **BRAT** 설치
2. BRAT 설정 → `Add a beta plugin for testing` → `ai4pastor/a4p-pastoral-visit` 입력
3. 커뮤니티 플러그인 목록에서 **A4P Pastoral Visit** 활성화
4. 플러그인 설정에서 성도 폴더·심방일지 폴더 경로를 지정하고 **검증** 버튼으로 확인

## 데이터 규약

플러그인은 새 형식을 강요하지 않고, 아래 볼트 구조를 자동화합니다:

- 성도 노트: `type: 교인노트`, 파일명 = 성도 이름
- 심방일지: `type: 심방일지`, 파일명 `{YYMMDD}_심방일지_{이름}`, 7개 고정 섹션
- 성도 노트의 `## 📝 심방 기록` / `## 📌 중요 심방 내용 (임베드)` 두 섹션을 플러그인이 관리
- 임베드 앵커: `#📝 대화내용` · `#🙏 기도제목` · `#💡 후속조치` (일지 헤딩과 문자 단위 일치 필요)

자세한 설계는 [docs/01-기획서.md](docs/01-기획서.md) 참조.

## 개발

```bash
npm install
npm run dev     # watch 빌드
npm run build   # 타입체크 + production 빌드
npm test        # vitest (순수 로직 단위 테스트)
node scripts/e2e-check.mjs  # 실제 볼트 데이터 대상 반영 로직 검증 (읽기 전용)
```
