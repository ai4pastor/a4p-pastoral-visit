## 5. 설정 스키마 초안

```typescript
interface PastoralVisitSettings {
  /** 성도 노트 폴더 (교인노트 스캔 대상) */
  memberFolder: string;        // 기본 "400. Education & Ministry/460. 성도"
  /** 심방일지 폴더 */
  visitFolder: string;         // 기본 memberFolder + "/심방일지"
  /** 장기 미심방 기준 (개월) */
  staleVisitMonths: number;    // 기본 6
  /** 새등록 성도 기준 (일) */
  newMemberDays: number;       // 기본 90
  /** 민감정보 화면 마스킹 */
  maskSensitiveFields: boolean; // 기본 true
  /** 생일 알림 범위 (일) */
  birthdayWindowDays: number;  // 기본 14
  /** 심방유형 목록 (커스터마이즈 가능) */
  visitTypes: string[];        // 기본 ["정기심방", "특별심방", "위로심방"]
  /** 일지 생성 시 world/route 분류 자동 삽입 */
  insertWordClassification: boolean; // 기본 true — "[[📩 208 상담 & 목양]]" / "[[📝기록]]"
}
```

- 저장 형태: `{ settings: PastoralVisitSettings }` 래퍼 (a4p 관례).
- SettingTab 구성: ① 폴더 경로 2개 + **검증 버튼**(폴더 존재·교인노트 개수 표시) ② 대시보드 기준값 3개 ③ 개인정보(마스킹 토글 + **동기화·git 노출 점검 버튼**) ④ 고급(심방유형 목록, WORD 분류 토글).

## 6. 핵심 구현 노트

### 6.1 인덱스 (`member-index.ts`)

- 별도 DB 없음. `app.metadataCache`의 프론트매터 캐시로 성도(`type: 교인노트`)·일지(`type: 심방일지`) 목록을 메모리에 구축.
- `metadataCache.on("changed")` + `vault.on("rename"/"delete")` 이벤트로 증분 갱신 (`registerEvent`).
- 파생 계산: 성도별 마지막 심방일(일지 `날짜` max), 미반영 일지(`반영` 필드 부재), 생일 D-day, 등록 경과일.

### 6.2 섹션 헤딩 상수 (`constants.ts`)

```typescript
export const VISIT_SECTIONS = {
  basicInfo: "## 📋 기본정보",
  visitInfo: "## 📍 심방정보",
  conversation: "## 📝 대화내용",
  prayer: "## 🙏 기도제목",
  church: "## ⛪ 교회 관련",
  observation: "## 🔍 관찰 및 평가",
  followUp: "## 💡 후속조치",
} as const;

export const MEMBER_SECTIONS = {
  visitLog: "## 📝 심방 기록",
  embeds: "## 📌 중요 심방 내용 (임베드)",
} as const;

/** 성도 노트 임베드 앵커 — 헤딩 텍스트(## 제외)와 정확히 일치해야 함 */
export const EMBED_ANCHORS = ["📝 대화내용", "🙏 기도제목", "💡 후속조치"] as const;
```

기존 볼트 샘플의 헤딩과 **문자 단위로 동일**해야 한다 (이모지 포함). 임베드 앵커 3종이 이 플러그인의 하위 호환성 계약.

### 6.3 반영 로직 (`sync.ts`) — 안전성이 최우선

1. 성도 노트 본문에서 `MEMBER_SECTIONS` 두 헤딩의 범위를 탐지 (다음 `## ` 헤딩 또는 EOF까지)
2. 섹션 끝(빈 줄 정리 후)에 **append만** — 기존 줄은 어떤 경우에도 수정·삭제하지 않음
3. 날짜 비교: 새 일지가 기존 마지막 항목보다 이르면 날짜순 삽입 위치 계산 (미리보기에 표시)
4. 헤딩 부재 시: 미리보기에 "섹션을 새로 만듭니다" 경고 → 승인 시 문서 말미에 헤딩+내용 생성
5. 반영 성공 후 `processFrontMatter`로 일지에 `반영: true`, 성도 노트에 `심방상태: 완료` (체크박스 승인 시)
6. 요약 자동 제안: 일지 `📝 대화내용` 섹션에서 `**주제 라벨:**` 볼드 패턴 추출 → `{심방유형} ({날짜}), {라벨1}, {라벨2}` 조립. 순수 함수로 분리해 vitest 테스트.

### 6.4 후속조치 토글 (`actions.ts`)

- 일지 파일의 `## 💡 후속조치` 섹션 내 `- [ ]`/`- [x]` 라인 파싱 (라인 번호 보존)
- 토글 시 `vault.process(file, ...)`로 **해당 라인만** 문자열 치환 — 라인 내용 일치 검증 후 변경 (동시 편집 안전)

### 6.5 마스킹 (표시 레이어)

- 패널·모달 렌더링 시점에 연락처/생년월일을 정규식 치환 (`010-****-5678`)
- 파일·클립보드에는 원문 유지. 상태바 아이콘으로 토글 상태 표시.

## 7. 배포

1. **BRAT 베타 배포** (README에 설치 안내): `ai4pastor/a4p-pastoral-visit` — 수강생은 BRAT로 설치
2. **GitHub Release 자동화**: 태그 push → build → `main.js`/`manifest.json`/`styles.css` 검증 → release 생성
3. 리포는 GitHub **ai4pastor 조직** (플러그인 리포 규칙), **private 시작** → 수강생 공개 시점에 결정
4. `.gitignore`: `node_modules/`, `main.js`, `data.json` (a4p-image 것 복사)
5. 실볼트 이관: 심볼릭 링크 금지, 빌드 산출물 3종 **복사** (dev 빌드 전파 방지)
